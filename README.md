# 桌面小灵宠 · Desktop Spirit Pet

使用 Windows PowerShell 5.1 与 WPF 的桌面悬浮宠物，无需安装额外运行时。

## 启动与操作

双击 `start.bat`，或在项目目录运行：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\pet.ps1
```

- 拖动宠物或面板换位置；单击宠物收起或展开，单击磁盘行展开各盘容量。
- 大小滑条和右键菜单可缩放（45%–140%）；普通滚轮不会误改变大小，使用 `Ctrl + 滚轮` 才会缩放。点击宠物可收起或展开数据。
- 右键可切换置顶、开机启动、减少动画、公网位置查询、隐藏地址，或隐藏到托盘；托盘右键可显示、隐藏和退出，重复启动会唤回已有窗口。
- 双击托盘图标可以恢复窗口。关闭按钮隐藏到托盘；“让小灵离开”或托盘“退出”才会结束程序。

启动脚本固定使用 Windows PowerShell 5.1；PowerShell 7 不属于本项目的界面验收目标。`ExecutionPolicy Bypass` 只作用于启动进程，不修改系统持久执行策略。所有 PowerShell 源文件采用 UTF-8 BOM 编码。

## 数据与性能

- CPU、内存、网络及电池：后台目标周期 1 秒。首页存储优先显示系统盘剩余空间，并提示快满状态。
- GPU：独立后台目标周期 3 秒，按物理引擎汇总进程负载，再取最忙引擎；不是多块 GPU 的平均值。
- 频率和热区：缓存 5 秒；磁盘容量：缓存 30 秒。
- 性能计数器保留前后采样点，首次速率读数需要预热；初始化和驱动读取仍可能需要数秒，目标周期不保证慢设备上的实际耗时。
- 硬件信息初始化后缓存；网卡动态发现。失败的性能计数器等待 30 秒再尝试。
- 数据整体超过 10 秒未更新或后台采样失败时显示过期提示；缺失数据不冒充 0% 使用率。
- 减少动画或最小化时降低界面定时器频率。读取公网信息的任务独立运行，不阻塞硬件快照。

热区是固件提供的温度，不等同于 CPU 核心温度。GPU、温度、频率和其他计数器取决于驱动、系统语言及设备支持。GPU 名称仅为识别信息，使用率取所有可读 GPU 引擎中的最大值。网络速率直接显示当前下载/上传速率，不代表套餐带宽占比；汇总未被筛除的接口，复杂虚拟网络可能无法完全排除重复统计。VPN 通过接口名称识别，属于启发式检测；分流 VPN 的公网出口不一定经过隧道。

## 设置与隐私

设置和日志保存在 `%LOCALAPPDATA%\桌面小灵宠`：

- `window.json`：窗口位置、大小、置顶、展开状态、隐私和功能开关。连续拖动滑条会合并保存请求，写入使用临时文件加原子替换。隐藏到托盘是临时状态，重启后仍会正常显示。
- `window.json.bak`：上一次保存的设置；无效 JSON 会备份为 `window.json.invalid` 并回退默认值。
- `log.txt`：错误日志，达到约 1 MB 时轮换为 `log.txt.1`。

**公网位置查询默认关闭。** 在右键菜单手动开启后，识别到 VPN 才通过 HTTPS 请求 `ipwho.is`。服务会看到请求的公网 IP；本机和隧道地址不作为参数发送。成功结果缓存 15 分钟，失败后至少等待 60 秒；识别到网络标识变化会清除旧结果。切换节点但接口地址不变时，结果可能保留至缓存到期。关闭查询会隐藏公网行并停止后续查询；已发出的请求可能仍在结束。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `pet.ps1` | 窗口生命周期、交互、动画及数据显示 |
| `ui.xaml` | 界面布局与样式 |
| `icons.ps1` | 地区及隧道图标绘制 |
| `sensors.ps1` | 硬件、网络、电池快照及格式化 |
| `counter-reader.ps1` | 本地化计数器名称、采样历史、缓存和失败退避 |
| `workers.ps1` | 独立硬件、GPU、位置任务及资源释放 |
| `state.ps1` | 设置校验、原子保存、日志轮换 |
| `tests/offline.ps1` | 无网络、无硬件依赖的回归测试 |
| `tests/benchmark.ps1` | 不打印机器名称和 IP 的采样耗时检查 |

## 检查

```powershell
# 离线测试：格式转换、GPU 汇总、网络请求退避、设置及脚本解析
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\offline.ps1

# 本机采样性能；不发起公网查询
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\benchmark.ps1

# 真实 WPF 与后台任务冒烟测试，约 20 秒自动退出，不修改现有设置
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\pet.ps1 -SmokeTest

# 硬件诊断：会输出机器及内网地址，请勿直接公开
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\pet.ps1 -SelfTest

# 位置标签示例
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\check-place.ps1
```

`-Shot` 在首个有效 CPU 快照后写入项目目录的 `preview.png`，可能包含机器信息和 IP，请勿直接公开。可与 `-SmokeTest` 一起使用。

## 故障排查

- 找不到窗口：双击托盘图标；或右键选择“找回窗口 / 重置大小”。多屏恢复使用物理像素定位，混合 DPI 的实际表现还需在对应显示器配置上验证。
- 长期无读数：查看状态提示、悬浮提示及日志；缺少传感器时不需要反复重启。先用上面的硬件诊断命令确认系统是否提供读数。
- 启动失败：在终端运行启动命令查看错误。保持所有模块与 `ui.xaml` 一起，不要只复制 `pet.ps1`。
- 重置配置：退出后将 `window.json` 改名，再启动。
- 取消开机启动：取消右键菜单勾选；也可从 Windows 启动文件夹删除“桌面小灵宠.lnk”。移动项目目录后重新开启一次启动项。

## 本次体验升级（2026-10-22）

参考了 `MerZlin/dsh-pet-indesktop` 与 `PC2005-cloud/dsh-pet` 的桌面对象管理和交互设计：独立托盘管理、可恢复的显示状态、点击反馈、减少误操作。当前版本保留本项目的 WPF 与实时硬件监控定位，没有复制对方代码、动画或其他素材。

- 关闭按钮隐藏到托盘，托盘右键可显示、隐藏、退出。
- 再次启动会请求现有窗口显示；隐藏状态不导致后台采样进程退出。
- `Ctrl + 滚轮` 缩放，普通滚轮不改变大小；缩放范围为 45%–140%。
- 支持隐藏地址和设备信息；存储行优先显示系统盘或最需要关注的盘剩余空间。
- 网络直接显示下载/上传，GPU 负载参与忙碌状态；点击宠物会短暂回应。

验证入口仍为 `tests/offline.ps1`、`tests/benchmark.ps1` 和 `pet.ps1 -SmokeTest`。混合 DPI 多屏与透明区域点击穿透仍需对应桌面配置实测。
